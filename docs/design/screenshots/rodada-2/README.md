# Segunda rodada — um mundo de descobertas

Chromium real em 22/10/2026. Viewports emulados, não aparelhos físicos. Capturas estáticas com movimento reduzido, fontes prontas e fotografias visíveis decodificadas. Galeria reposicionada no início.

- Hero: 1440, 1366, 768, 390 e 360 px.
- Páginas completas: 1440 e 390 px.
- Mapas: 1440 e 390 px, Google Maps carregado com o endereço configurado.
- Logo: transparência sobre creme, azul e amarelo. Letras e cores preservadas; suporte claro utilizado sobre o fundo escuro do rodapé.

As capturas da primeira rodada estão no diretório superior, para comparação. A versão vigente é esta.

As páginas integrais combinam a captura longa com o recorte real do componente de mapa, no mesmo tamanho e posição, para contornar a supressão de pintura de iframe fora da dobra no Chromium. Os arquivos mapa-*.webp são capturas reais separadas do componente inteiro. Nenhum mapa ou conteúdo da interface foi gerado.
